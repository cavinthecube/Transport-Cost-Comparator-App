# Transport Cost Comparator 🚗🚌🚆

## Overview

Transport Cost Comparator is an Android application developed to help South African commuters estimate and compare their transport costs.

The application allows users to enter their transport information, select their travel dates, calculate their daily and monthly transport costs, and receive a cost category and recommendation based on their monthly transport expenses.

The application also stores transport reports locally using SQLite.

## Features

- 🚗 Select a transport category
- 📝 Enter transport information
- 📍 Enter daily travel distance
- 💰 Enter cost per kilometre
- 📅 Select travel start and end dates using Android DatePicker
- 🧮 Calculate:
  - Daily transport cost
  - Monthly transport cost
  - Monthly distance travelled
- 📊 Categorise transport costs
- 💡 Provide transport-saving recommendations
- 💾 Save transport reports locally using SQLite
- 🔊 Listen to an audio explanation using the built-in audio player
